# Ferramentas de Teste de Anonimato

> **Aviso**: referência para verificação de privacidade em configurações próprias. URLs não validados automaticamente.

| Site | URL | Descrição |
|---|---|---|
| IPLeak | https://ipleak.net/ | Teste completo de vazamento: IP real, DNS, WebRTC, geolocalização e fingerprint do navegador |
| BrowserLeaks | https://browserleaks.com/ | Detecção de fingerprinting de navegador: Canvas, WebGL, fontes, WebRTC, áudio e mais |
| DNS Leak Test | https://dnsleaktest.com/ | Verifica se as consultas DNS estão vazando fora do túnel VPN/proxy |
| Whoer | https://whoer.net/ | Análise de anonimato: IP, DNS, WebRTC, JavaScript, Flash e nível de anonimato estimado |
